# iShop

The shopping agent in your iPhone.

Send iShop a shopping brief in iMessage. It searches Shopify inventory, builds a bundle within your budget and constraints, lets you lock or replace items, and creates merchant checkout links after you approve the cart.

## Run locally

```sh
cd hackathon
cp .env.example .env
bun install
bun start
```

Fill in `.env` before starting. Run the tests with `bun test`.
